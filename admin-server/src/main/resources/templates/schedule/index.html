Расписание запусков

К скриптам
В назначенное время сервер сам создаёт запуск с заданными переменными и интенсивностью по операциям. Если свободных генераторов в этот момент не хватает, запуск пропускается и помечается ошибкой с причиной (в очередь он не ставится). Запланировать запуск можно на странице запуска скрипта.
Запланированных запусков нет.
