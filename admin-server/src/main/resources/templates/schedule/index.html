Импорт списка тестов (JSON)
Каждый тест — скрипт и профиль нагрузки; тесты без runAt встают в расписание строго друг за другом с паузой не менее 5 минут. Необязательные поля: gapMinutes, runAt, generators, count, env, shift.
Перетащите JSON-файл списка тестов сюда или выберите на компьютере
Полный пример JSON (все поля: gapMinutes, script, profile, runAt, count, generators, env/секреты, shift) 
{
  "gapMinutes": 5,
  "tests": [
    {
      "script": "Платежи",
      "profile": "Поиск максимума (3 ступени)",
      "count": 2,
      "shift": true
    },
    {
      "script": "Платежи",
      "profile": "Стабильность 1ч",
      "runAt": "2026-11-23T22:00:00+03:00",
      "generators": ["gen-01", "gen-02"],
      "env": {
        "BASE_URL": "https://stand.example",
        "API_TOKEN": "${secret:API_TOKEN}"
      },
      "shift": false
    },
    {
      "script": "Каталог",
      "count": 1
    }
  ]
}
Импорт профилей нагрузки (JSON)
Профили для разных скриптов одним файлом: массив или {"profiles": [...]}. У каждого — script (имя скрипта), name (имя профиля) и конфиг нагрузки (operations, env, stop…).
