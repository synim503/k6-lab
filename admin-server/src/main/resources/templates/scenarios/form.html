Переменные окружения и секреты
KEY=VALUE по строкам. Секреты: ${secret:NAME} — подставляются только на агенте и маскируются во всех логах. Доступные секреты: управление секретами
Тестовые данные
SHARED — файл одинаковый на всех генераторах. SPLIT — агент перед стартом режет файл на непересекающиеся непрерывные блоки пропорционально своему execution segment и подменяет файл по тому же пути; скрипт не меняется.
Критерии остановки (серверные)
Проверка раз в 15 с по Prometheus, только на участках удержания (после разгона). abortOnFail не используется.
Успешность ступени (пороги по умолчанию)
Перцентиль и допустимый % ошибок берутся из SLA операции в модели.
Внимание: изменения модели и профиля перестанут влиять на конфиг; ответственность за согласованность (VU, timeUnit, ступени, thresholds) — на вас. abortOnFail использовать нельзя.
