Prometheus
В классическом режиме агент на генераторе сам преобразует метрики k6; перцентили считаются тем же histogram_quantile по суммарным корзинам всех генераторов.
Как часто каждый генератор отправляет метрики в Prometheus (5–60). Больше интервал — меньше нагрузка на Prometheus, но дольше задержка метрик на графиках. По умолчанию 10. В классическом режиме отправляются только нужные гистограммы (время итерации и операции, http_req_duration): остальные HTTP-гистограммы k6 отбрасываются агентом.
Prometheus должен быть запущен с --web.enable-remote-write-receiver; для режима native histograms — ещё и с --enable-feature=native-histograms.
Диагностика связки k6 → Prometheus

Имена метрик k6 в Prometheus
Имена зависят от версии k6 и настроек remote write; меняйте, если в вашем Prometheus они другие.
Хранение и логи
Результаты и отчёты хранятся без ограничения срока.
