Prometheus
В классическом режиме агент на генераторе сам преобразует метрики k6; перцентили считаются тем же histogram_quantile по суммарным корзинам всех генераторов.
Как часто каждый генератор отправляет метрики в Prometheus (5–60). Больше интервал — меньше нагрузка на Prometheus, но дольше задержка метрик на графиках. По умолчанию 10. В классическом режиме отправляются только нужные гистограммы (время итерации и операции, http_req_duration): остальные HTTP-гистограммы k6 отбрасываются агентом.
Prometheus должен быть запущен с --web.enable-remote-write-receiver; для режима native histograms — ещё и с --enable-feature=native-histograms.

Какие метрики отправляют агенты (белый список)
Нужные админке отправляются всегда, добавлять их не нужно:
Время итерации, время операции и http_req_duration; остальные гистограммы k6 (blocked, connecting, tls_handshaking, sending, waiting, receiving) отбрасываются: каждая даёт ~170 серий на набор меток.
Каждый уникальный адрес — отдельный набор рядов в Prometheus (у гистограммы ~170 рядов на генератор). Если в адресах скрипта есть идентификаторы и адреса не сгруппированы тегом name в самом скрипте, отключите: разбивка по операциям, статусам и методам останется.
Маска — имя метрики в Prometheus, * заменяет любую часть; для гистограмм сверяется имя без _bucket/_count/_sum. Если список не пуст, остальные метрики агент отбрасывает (включая прочие гистограммы), а флажок выше не действует. Пустой список — отправляются все метрики (с учётом флажка). Работает в режиме классических гистограмм; применяется к следующим запускам.
Хранение и логи
Результаты и отчёты хранятся без ограничения срока.
Графики отчёта Не сохранено
Оформление графиков в HTML, PDF и Word-отчётах. Высота — это высота самого графика: легенда снизу добавляется к ней, поэтому график не сжимается, даже если в нём много рядов. Если рядов больше лимита легенды, в ней остаются ряды с наибольшим максимумом.
