Свои графики попадают в HTML, PDF и Word-отчёт каждого запуска этого скрипта, после стандартных. Вставьте PromQL и дайте графику имя. В запросе можно использовать {run_id} (метка test_run_id запуска) и {range} (окно для rate/increase, например 45s). Ряды рисуются по меткам результата, в легенде — Last / Mean / Max. Пример: sum(rate(http_reqs_total{test_run_id="{run_id}"}[{range}]))
График с уже существующим именем будет обновлён.
