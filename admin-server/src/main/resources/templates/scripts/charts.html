    Подстановки в PromQL
    {run_id} — метка test_run_id текущего запуска.
    {range} — окно для rate() / increase() (например 45s).
    $имя / ${имя} — переменная графика (задаётся прямо внутри каждого графика; если не задана — берётся из «Общих переменных» скрипта).
    Легенда и заголовок
    Пустая легенда — автоматическая подпись по меткам результата.
    {{метка}} — подстановка значения метки как в Grafana (например {{instance}}).
    В имени графика переменные тоже раскрываются; в легенде выводятся Last / Mean / Max.
    Единицы и порядок
    Единицы Б и Б/с автоматически масштабируются в КБ, МБ, ГБ, ТБ.
    Перетаскивайте графики в списке слева за — в таком порядке они попадут в HTML, PDF и Word-отчёт.
    Общие переменные скрипта (по умолчанию) Подставляются, если переменная не задана у конкретного графика
