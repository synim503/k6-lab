Файлы последней версии отсутствуют в хранилище сервера. Скрипт нельзя запустить и скачать. Обычно так бывает после переустановки админки без переноса каталогов config/ и data/ прежней установки (или после смены K6LAB_STORAGE_DIR). Верните каталог хранилища на место либо загрузите скрипт заново на вкладке «Версии».
Скрипт сейчас выполняется. Новый запуск начнётся после завершения текущего.
