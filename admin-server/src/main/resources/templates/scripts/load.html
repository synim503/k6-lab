В последней версии скрипта нет функций операций: Они убраны из списка и не участвуют в запуске. Если вернуть версию с этими функциями (откат), их нагрузка вернётся, пока вы не сохранили форму.
Стадий в прогреве
Общий для всех сценариев со стадиями (ramping-*): в каждом появляются жёлтые стадии прогрева. Ошибки, dropped и время ответа в них не попадают в итоги и SLA, на графиках они выделены. Выключение превращает стадии прогрева в обычные. У constant-* прогрев — длительность в самом сценарии.

Тестовые данные
как делить файлы данных между генераторами
Файл данныхРежимЗаголовокРасходуется
«Общий» — файл одинаковый на всех генераторах. «Нарезка» — агент перед стартом режет файл на непересекающиеся части по доле своего генератора и подменяет файл по тому же пути; скрипт не меняется.

Итоговый конфиг k6, который уйдёт на генераторы. Правится только то, чего нет в конструкторе: сохраняется лишь отличие от расчётного конфига, поэтому правки остаются при изменении операций. Конфиг проверяет сам k6.
