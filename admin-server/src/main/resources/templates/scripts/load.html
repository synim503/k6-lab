Нагрузка:

К скрипту
В последней версии скрипта нет функций операций: Они убраны из списка и не участвуют в запуске. Если вернуть версию с этими функциями (откат), их нагрузка вернётся, пока вы не сохранили форму.

«По профилю» — интенсивность в операциях в секунду, разгон, удержание и уровень % задаются в форме ниже (операция с пустой или нулевой нагрузкой в запуске не участвует). Любой другой исполнитель работает по своим параметрам под строкой операции, без ступеней профиля. Для одной функции можно добавить несколько сценариев («＋ сценарий»): у каждого свой исполнитель, параметры и SLA. Список функций берётся из последней версии скрипта.

Есть ручные правки конфига:
Итоговый конфиг k6, который уйдёт на генераторы. Его можно править: например maxVUs, preAllocatedVUs, gracefulStop у сценария или опции верхнего уровня. Сохраняется только отличие от расчётного конфига, поэтому правки остаются при изменении нагрузки. Конфиг проверяет сам k6. Не меняйте rate, stages и executor: график, расчёт и отчёт строятся по плану нагрузки.
