Нагрузка задаётся в операциях в секунду. Операция с пустой или нулевой нагрузкой в запуске не участвует. Список функций берётся из последней версии скрипта.
Длительность
Уровень — доля от заданной интенсивности: при 50% каждая операция идёт с половинной нагрузкой.
Переменные окружения и секреты
KEY=VALUE по строкам. Секреты: ${secret:NAME} подставляются только на агенте и маскируются во всех логах. Доступные секреты: управление секретами
