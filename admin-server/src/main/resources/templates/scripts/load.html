Импорт и экспорт профилей (JSON)
Массив профилей или {"profiles": [...]}. Профиль с существующим именем обновляется. Все профили проверяются целиком; если хотя бы один содержит ошибку, не сохраняется ни один.
Перетащите JSON-файл профилей сюда или выберите на компьютере
