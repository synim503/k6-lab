Что происходит при загрузке
  • Скрипт проверяется через k6 inspect, функции становятся операциями нагрузки.
  • Сценарии, пороги и теги из options вырезаются: нагрузку задаёте вы на вкладке «Нагрузка».
  • Каждая загрузка создаёт новую версию, старые можно вернуть.
