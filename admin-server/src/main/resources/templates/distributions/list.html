Файлы, которые админка доставляет на генераторы: агент, k6 и JRE. Генераторам интернет не нужен.
Загрузить версию
Агент: бинарь Go (linux-amd64 или linux-arm64) или jar. k6: бинарь под архитектуру. JRE 21: tar.gz, только для Java-агента.
Первая загруженная версия каждого вида и архитектуры становится версией по умолчанию автоматически.
