Определение — JSON: params (параметры профиля с умолчаниями) и blocks (блоки ступеней). Блок с repeat повторяется count раз, переменная var — номер повтора с 0. В выражениях level, ramp, hold доступны параметры, + − * / ^, скобки, min max round ceil floor abs. Код не исполняется: выражения считает безопасный вычислитель.
