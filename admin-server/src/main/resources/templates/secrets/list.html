Секреты скриптов

Пароли, токены и ключи для скриптов. Значения шифруются и нигде не показываются, в логах маскируются.
Создать или заменить секрет
Чтобы изменить только описание, оставьте значение пустым. В переменных окружения скрипта секрет подставляется ссылкой ${secret:ИМЯ} и только на агенте.
