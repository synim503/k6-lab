k6-lab, портативная версия
==========================
1. Запуск: start.bat (Windows) или ./start.sh (Linux). Нужна Java 17+ и PostgreSQL 16 (любой доступный, своя база).
2. При первом запуске откройте http://localhost:8080 - мастер спросит адрес, имя базы, пользователя и пароль PostgreSQL,
   проверит подключение и сохранит настройки в config/k6lab.properties (там же ключ шифрования - сохраните файл!).
   Подготовка базы: create user k6lab with password '...'; create database k6lab owner k6lab;
3. Дистрибутивы (агент на Go, k6 и k6 с расширениями xk6 для linux-amd64/arm64) подхватываются из dist/ сами.
4. Дальше в интерфейсе: Генераторы -> Добавить сервер (адрес, логин, пароль SSH) -> Тесты -> Создать тест -> Запустить.
Порты: 8080 (интерфейс), 47331 (агенты; должен быть доступен с серверов-генераторов). Меняются K6LAB_HTTP_PORT / K6LAB_AGENT_PORT.
Расширения xk6 в сборке "full": kafka, sql (postgres, mysql), faker, mqtt, sse (импорты k6/x/kafka, k6/x/sql, k6/x/faker, k6/x/mqtt, k6/x/sse).
Сборку "full" выбирайте у генератора при добавлении (расширенная форма) — обычный k6 расширений не содержит.

Как служба (автозапуск, перезапуск при падении):
  Linux:   после первой настройки через start.sh -> sudo ./install-service.sh   (удалить: sudo ./uninstall-service.sh)
  Windows: от администратора install-service.bat                                 (удалить: uninstall-service.bat)
Агенты на серверах-генераторах ставятся админкой как systemd-служба (режим «системный» по умолчанию), без ручных действий.
